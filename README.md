# Todo Manager App

A modern Todo Manager built using Flask, SQLite and Bootstrap.

## Features

* Add Tasks
* Edit Tasks
* Delete Tasks
* Complete Tasks
* Search Tasks
* Filter Tasks
* Dashboard Statistics

## Technologies Used

* Python
* Flask
* SQLite
* Bootstrap 5
* HTML/CSS

## Installation

```bash
git clone <repo-link>
cd web-todo-list

pip install -r requirements.txt

python app.py
```
